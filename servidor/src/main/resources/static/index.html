Todos os downloads já vêm ligados a este servidor. Crie a conta na tela de entrada do jogo, e as suas vitórias passam a contar no ranking.

Android

Para celular com Android 8 ou mais novo. Os controles ficam na tela, e o jogo se ajusta na vertical e na horizontal.

Baixar o APK

Como instalar
  1. Baixe o APK pelo celular.
  2. Abra o arquivo e permita a instalação de "fontes desconhecidas" quando o Android pedir.
  3. Cada versão nova sai com outra assinatura. Se a instalação falhar, desinstale a versão antiga e tente de novo.

Windows

O Java vem dentro do pacote. Basta descompactar numa pasta sua e abrir, sem instalar e sem pedir administrador.

Baixar para Windows

Como abrir
  1. Descompacte o zip em Documentos ou na Área de Trabalho.
  2. Abra Missao Marte.exe, dentro da pasta Missao Marte.
  3. Na primeira vez, o Windows pode mostrar "O Windows protegeu o computador". Clique em "Mais informações" e depois em "Executar assim mesmo". O aviso aparece porque o jogo não tem assinatura digital paga.

Mac

O Java também vem dentro do app. Escolha pelo processador: no menu Apple → Sobre Este Mac, "Apple M1" (ou M2, M3, M4) é Apple Silicon, e "Intel" é Intel.

Baixar para Apple Silicon

Baixar para Intel

Como abrir
  1. Dê dois cliques no zip e arraste Missao Marte para Aplicativos.
  2. Na primeira vez, o macOS diz que não pôde verificar o app, porque ele não tem a assinatura paga da Apple. Feche o aviso, abra Ajustes do Sistema → Privacidade e Segurança e clique em "Abrir Mesmo Assim".
  3. Quem prefere o Terminal pode liberar com xattr -dr com.apple.quarantine "/Applications/Missao Marte.app".
Linux ou outro sistema

Esta versão precisa do Java 17 (ou mais novo) instalado. Baixar o .zip com Java . Descompacte e rode bin/missao-marte.

Teclado no computador: no modo clássico, as setas ou WASD movem a nave, Espaço embarca e Esc aborta. Na pilotagem, ← e → giram e ↑ liga o motor. Nas versões para Windows e Mac, o ranking local fica na pasta .missao-marte do seu usuário.
