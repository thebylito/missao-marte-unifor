Missão Marte

Pilote a nave pelas cavernas de Marte, resgate os passageiros e volte à base antes que o combustível acabe. Os melhores pilotos entram no ranking global.

As duas versões já vêm apontando para este servidor: crie a sua conta dentro do jogo e a vitória entra no ranking abaixo.

Android

APK para celulares com Android 8 ou mais novo. Controles de toque, retrato e paisagem.

Baixar APK

Como instalar
  1. Baixe o APK pelo celular.
  2. Abra o arquivo e permita a instalação de "fontes desconhecidas" quando o Android pedir.
  3. Se já tiver uma versão antiga instalada e a instalação falhar, desinstale a antiga antes.

Desktop

Windows, macOS e Linux. Precisa do Java 17 ou mais novo instalado.

Baixar .zip

Como jogar
  1. Descompacte o arquivo.
  2. Rode bin/missao-marte (macOS e Linux) ou bin\missao-marte.bat (Windows).
  3. No modo clássico: setas ou WASD movem, Espaço embarca, Esc aborta. Na pilotagem: ← → giram e ↑ liga o motor.
